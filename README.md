Este repositório contém projetos e modelos relacionados à  Banco de Dados. O objetivo é aplicar conceitos de modelagem, criação e manipulação de bancos de dados utilizando SQL.  🚀  Modelagem Conceitual (Diagrama ER)  Lógica ,Física  Criação de tabelas (DDL)  Manipulação de dados (DML)  Consultas SQL (SELECT, JOIN, GROUP BY, etc.)  


📌 Sobre o Projeto

Este repositório reúne projetos, exercícios e práticas desenvolvidas na área de Banco de Dados, com foco em modelagem, estruturação e manipulação de dados utilizando SQL e SGBDs relacionais.

O objetivo é aplicar conceitos fundamentais e avançados, seguindo boas práticas de organização, normalização e integridade de dados.

🧠 Conteúdos Abordados

✔ Modelagem Conceitual (Diagrama ER)
✔ Modelagem Lógica e Física
✔ Criação de Tabelas (DDL)
✔ Manipulação de Dados (DML)
✔ Consultas SQL (SELECT, JOIN, GROUP BY, HAVING)
✔ Normalização (1FN, 2FN, 3FN)
✔ Relacionamentos e Integridade Referencial
